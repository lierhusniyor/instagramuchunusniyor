# YOTOQXONA — Instagram animatsion serial (18–25 yosh)

Format: har kuni 1 qism (30–45 soniya, vertikal 9:16), har hafta 1 sezon (7 qism).
Janr: qora hazil + hayotiy muammolar. Ochiq/18+ sahna YO'Q (Instagram va Kling qoidalari).

## Papkalar
- agents/ — 7 ta agent ko'rsatmasi (har biri alohida chatga/agentga beriladi)
- bible/characters.md — qahramonlar (o'zgarmas tavsif)
- bible/kling_style.md — Kling uchun qotirilgan uslub va negative promptlar
- season1.md — 1-sezon rejasi (7 qism)
- episodes/ep01.md — 1-qism: senariy + Kling promptlari + caption

## Haftalik ish tartibi
1. Yakshanba: trend_researcher → showrunner (keyingi sezon rejasi)
2. Dushanba: 7 qism senariysi (writer + punchup)
3. Seshanba–Chorshanba: Kling'da generatsiya (prompt_engineer)
4. Payshanba: qa_checker + montaj
5. Har kuni 07:30–08:30 yoki 11:30–12:30 (Moskva/Toshkent vaqtiga moslang): publisher
