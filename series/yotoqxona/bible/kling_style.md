# Kling uslub bloki (har promptga so'zma-so'z)

STYLE: 2D cartoon animation, adult animated comedy style, bold outlines, flat vibrant colors, expressive faces, vertical 9:16, smooth simple motion, consistent character design

NEGATIVE (har safar bir xil):
different hairstyle, changed clothes, different face, extra fingers, realistic photo, 3D render, blurry, distorted face, text artifacts, watermark, nudity, gore

## Ish tartibi (Kling 3.0)
1. Har qahramon uchun master rasm yarating (CHARACTER_* bloki + STYLE) — Character ID / reference sifatida saqlang.
2. Keyingi barcha klipda shu referenceni ulang va CHARACTER_* blokini o'zgartirmay qo'ying.
3. Klip tugagach, oxirgi kadrni keyingi klipga boshlang'ich kadr qilib bering (davomiylik uchun).
4. Qahramon "siljisa": promptni birinchi muvaffaqiyatli versiyaga qayta moslang.
